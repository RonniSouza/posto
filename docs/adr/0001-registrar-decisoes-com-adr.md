# ADR 0001 — Registrar decisões de arquitetura com ADRs

- Status: aceito
- Data: 2026-11-24

## Contexto
O projeto é de portfólio e deve deixar claro o porquê de cada escolha técnica.

## Decisão
Toda decisão relevante vira um arquivo em `docs/adr/NNNN-titulo.md` com Contexto, Decisão e Consequências.

## Consequências
Histórico de decisões versionado junto com o código; serve de material para entrevistas.
